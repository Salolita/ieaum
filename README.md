# IEAUM

سایت اصلی مهندسان صنایع دانشگاه آزاد مشهد و منبع کد حساب‌ها و ربات تلگرام.

- سایت اصلی در index.html و styles.css است و روی ieaum.ir منتشر می‌شود.
- کد حساب‌ها، تأیید مدیر، آزمون‌ها و ربات در portal/server و portal/api است.
- مینی‌اپ ثبت‌نام و بازیابی رمز در portal/client است.
- سوابق پایگاه داده در portal/supabase/migrations است.

## اجرا

npm ci
npm run build
npm run lint
npm test
npm run build:portal

خروجی سایت اصلی dist است. ریشهٔ پروژهٔ Vercel همان ریشهٔ مخزن باشد.

## انتشار ربات

بستهٔ @ieaum/platform از همین مخزن با شناسهٔ ثابت گیت به NumeraLab متصل می‌شود. فایل‌های آمادهٔ اجرا در portal/dist ثبت شده‌اند. بعد از تغییر کد ربات، build:portal را اجرا و تغییرات را ثبت کنید. سپس وابستگی NumeraLab را به شناسهٔ نسخهٔ جدید ارتقا دهید.

محل اجرای API و ربات همان پروژهٔ ورسل متصل به numeralab.ieaum.ir است. مسیر وب‌هوک، کوکی ورود، نشست‌ها و تنظیمات محرمانهٔ موجود حفظ می‌شوند. مالک کد ربات این مخزن است. NumeraLab فقط اتصال‌های کوچک و نسخهٔ ثابت این بسته را دارد. کلید محرمانه‌ای در بسته وجود ندارد.

راهنمای تنظیمات در portal/SETUP.md است. این جابه‌جایی نیازی به اجرای مهاجرت تازه روی Supabase ندارد.

## ارائه‌طوری

صفحهٔ فعال در public/egtesadkalan حفظ شده و API آن تا آماده‌شدن مخزن مستقل از مسیر فعلی نامرالب استفاده می‌کند. انتقال آن جداگانه انجام می‌شود تا ارائهٔ فعال قطع نشود.
