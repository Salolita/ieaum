# سایت معرفی IEAUM

سایت معرفی «مهندسان صنایع دانشگاه آزاد مشهد» یک سایت استاتیک فارسی و راست‌چین است. برای مشاهدهٔ محلی، فایل `index.html` را در مرورگر باز کنید. برای انتشار در Vercel، پوشهٔ `ieaum-site` را به عنوان Root Directory انتخاب کنید. اگر این پوشه خودش ریشهٔ مخزن جداگانه باشد، مقدار پیش‌فرض کافی است. Framework Preset روی Other باشد. فایل‌های همین پوشه خروجی قابل انتشارند و به نصب وابستگی یا دستور ساخت نیاز ندارند.

## ترتیب جابه‌جایی دامنه

سایت معرفی از پروژهٔ `ieaum-site` روی [ieaum.ir](https://ieaum.ir/) منتشر می‌شود. حل‌گر از پروژهٔ جداگانهٔ `numera-lab-v1` روی [numeralab.ieaum.ir](https://numeralab.ieaum.ir/) در دسترس است. ارتقای نامرالب از V1 به V2 در همان پروژهٔ حل‌گر انجام می‌شود.

برای انتشار خودکار سایت معرفی، در تنظیمات نصب GitHub App ورسل روی حساب `Salolita`، دسترسی به مخزن `Salolita/ieaum` را فعال کنید. سپس در بخش **Settings → Git** پروژهٔ موجود `ieaum-site`، همان مخزن را متصل کنید و شاخهٔ انتشار را روی `main` بررسی کنید.

## نمونهٔ پایلوت

- کلاس «محاسبات عددی مهندسی صنایع»، گروه آزمایشی ۱، یک استاد و سه دانشجوی ساختگی. ورود با دعوت استاد.
- آزمون «دونیم‌سازی»، معادلهٔ `x³ − x − 2 = 0` روی بازهٔ `[1, 2]`. سامانه مقادیر دو سر بازه و اولین نقطهٔ میانی را نشان می‌دهد. دانشجو علامت تابع در نقطهٔ میانی و بازهٔ بعدی را انتخاب می‌کند.
- پاسخ مورد انتظار برای استاد `f(1.5) = −0.125` و بازهٔ `[1.5, 2]` است. برای نمونه، هر پاسخ یک نمره دارد.
- سناریوی بررسی از انتشار آزمون و دریافت اعلان شروع می‌شود و با ثبت پاسخ و مشاهدهٔ نمره توسط استاد پایان می‌یابد.
